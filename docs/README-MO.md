# MoLumen — Mo's Start Here Page

You do not need to understand the technical files in this repository for normal website updates.

## Writing or publishing a new article

Read:

**`docs/how-to-write-and-publish-articles.md`**

Then use **Pages CMS → Write & Publish → Blog posts**.

## Updating other website content

Read:

**`docs/pages-cms-for-mo.md`**

It covers Current Sky, videos, readings/services, reference pages, FAQs, glossary, testimonials, images, downloads, and when to ask Claude for help.

## Technical problem or unusual change

Ask Claude/Claude Code rather than editing repository code yourself.

Examples include layout/design, navigation, booking, Kit, analytics, schema, Birth Time worksheet/PDF changes, failed builds, or a brand-new content type.

## The one publishing safety rule

For **Blog posts, Current Sky, and Videos**, keep **Draft ON** while working and turn it **OFF only after final review**.
