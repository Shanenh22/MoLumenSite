# Autonomous Development

## Start
1. Read Master Operating Manual.
2. Read Project Memory.
3. Read Decisions.
4. Read Backlog.
5. Inspect git status and recent changes.
6. Run useful baseline tests.
7. Verify whether prior findings still exist.

## Behavior
- implement rather than restating recommendations
- work through all code-safe items
- prefer shared fixes
- make reversible changes
- maintain tests
- do not ask routine technical questions
- do not deploy production unless explicitly instructed

## Finish
Update Project Memory, Changelog, Decisions if needed, and Backlog.
