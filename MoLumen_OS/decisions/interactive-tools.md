# Interactive Tool Decisions

- Interactive tools should remain site-owned, lightweight, accessible, and useful without unnecessary framework/runtime complexity.
- The Current Sky calendar must behave consistently across time zones; UTC/date-boundary behavior is regression-tested.
- Birth Time Confidence is a self-assessment aid, not a claim of astronomical certainty.
- Rising-sign preference is a user preference/enhancement, not a requirement for basic content access.
- Interactive-tool analytics follow the consent-aware shared tracking layer.
- Do not add Event schema or CMS fields merely because a UI is interactive; schema/CMS changes must match real content and editing requirements.
