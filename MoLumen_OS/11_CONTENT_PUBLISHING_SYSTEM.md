# Content Publishing System

## Goal
Mo should be able to add/update ordinary content without touching layout code, CSS, schema code or site architecture.

**Content goes into structured templates; the site supplies presentation automatically.**

## Supported types
- blog
- video
- Current Sky
- horoscope/lunation
- reference/educational page
- FAQ
- glossary
- lead magnet
- future owner-approved service

## Automation should cover where applicable
- metadata
- canonical
- author
- dates
- schema
- breadcrumbs
- related content
- newsletter CTA
- reading CTA
- Open Graph
- internal-link hooks
- sitemap inclusion

## Mo workflow
1. Copy correct template.
2. Fill OWNER INPUT fields.
3. Write/paste body.
4. Ask Claude Publisher to validate/publish.
5. Claude handles metadata, links, schema, accessibility and build.
6. Claude shows resulting changes.
7. Production publishing follows deployment rules.

If an ordinary blog or video requires component edits, improve the publishing system.
